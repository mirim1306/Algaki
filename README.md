# 알까기 능력물 🥚⚡

pygame 기반 2D 알까기 게임. 10가지 고유 능력을 가진 알로 대전합니다.

## 설치 & 실행

```bash
pip install pygame
python main.py
```

## 조작법

| 행동 | 방법 |
|------|------|
| 알 발사 | 내 알을 클릭 후 뒤로 드래그 → 놓으면 발사 |
| 능력 사용 | 내 알 선택 → `능력 사용` 버튼 클릭 |
| 능력 발동 | 능력 안내에 따라 알 또는 보드 위치 클릭 |
| 즉시 발동 능력 | `확인/발동` 버튼 클릭 (분신알, 투명알) |
| 능력 취소 | `취소` 버튼 |
| 재시작 | `R` 키 |

## 알 종류 (10가지)

| 알 | 능력 |
|----|------|
| 🟦 일반알 | 발사만 가능 |
| 🟩 방벽알 | 원하는 빈 위치에 방벽 생성 (알 위치 불가) |
| 🟪 봉인알 | 지정한 알 1개를 행동 불가 상태로 만듦 |
| 🟨 복사알 | 적 알의 능력을 복사하거나, 자신에게 부딪힌 알의 위력을 복사 (복사 위력 사용 시 발사도 동시 가능) |
| 🟧 분신알 | 주위에 분신 소환 후 원본·분신 위치를 랜덤 섞음 |
| 🔴 폭탄알 | 원하는 빈 위치에 지뢰 설치. 적 알이 접근하면 폭발 |
| 👻 투명알 | 투명화. 투명 상태에서도 발사 가능 |
| 🟣 염력알 | 지정한 적 알 파괴 → 반동으로 아군 알 1개 랜덤 파괴 → 염력알 자폭 |
| 🩵 얼음알 | 지정한 알을 슬립 상태로 만들어 더 잘 밀리게 함 |
| 💜 자석알 | 두 알을 선택해 자석으로 연결 → 서로 끌어당김 |

## 승리 조건

상대방의 알을 모두 보드 밖으로 밀어내거나 파괴하면 승리!

## 파일 구조

```
algaki/

├── requirements.txt
├── core/
│   ├── constants.py     # 상수·설정
│   ├── egg.py           # Egg / Barrier / Mine 클래스
│   ├── physics.py       # 충돌·물리 엔진
│   ├── abilities.py     # 10가지 능력 로직
│   └── game_state.py    # 게임 상태·턴 관리
└── ui/
    ├── renderer.py      # pygame 렌더러
    ├── buttons.py       # 버튼 컴포넌트
    └── input_handler.py # 마우스·키보드 입력 처리
```
